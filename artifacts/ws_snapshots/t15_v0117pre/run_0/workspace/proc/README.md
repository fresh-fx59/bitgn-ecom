# Proc

Projected commerce state lives here. Treat these files as source-of-truth runtime state.

- `/proc/catalog/` contains generated product records.
- `/proc/stores/` contains generated store records.
- `/proc/employees/` contains generated employee profiles.
- `/proc/customers/` contains generated customer profiles.
- `/proc/baskets/` contains generated customer baskets.
- `/proc/payments/` contains generated checkout payment records.
- `/proc/returns/` contains generated return workflow records.
